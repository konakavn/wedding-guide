# メコン旅のしおり（Yuichiro & Trâm Wedding）

結婚式（2026.10.18）に来てくれるゲスト向けの、ホーチミン・カントー・ロンスエンのおすすめガイド。
GitHub Pages で公開する静的サイトです。

| ファイル | 中身 |
|---|---|
| `data.js` | 都市ごとのおすすめ・行き方・ヒント・ひとことベトナム語（ここを編集すれば内容が変わる） |
| `config.js` | Google フォームとスプレッドシートの URL |
| `index.html` / `style.css` / `app.js` | 画面と動き |

## ゲスト投稿のしくみ（Google フォーム）

ゲストはフォームから投稿 → 回答スプレッドシートに貯まる → サイトがそれを読み込んで「みんなのおすすめ」に自動表示。GitHub アカウントは不要です。

### 1. フォームを作る（forms.google.com）
タイトル例：「メコン旅のおすすめを教えて！」。質問は次の6つ（**質問文に下線の言葉が入っていれば順番・文言は自由**）。

1. お<u>名前</u>（ニックネーム可）… 記述式
2. <u>都市</u> … ラジオボタン：ロンスエン／カントー／ホーチミン／その他
3. <u>ジャンル</u> … ラジオボタン：食べる・飲む／観光・体験／お土産・買い物
4. <u>店名・場所</u> … 記述式（必須）
5. <u>住所</u> または Google<u>マップ</u>のURL … 記述式
6. <u>おすすめ</u>ポイント・ひとこと … 段落

### 2. 回答をスプレッドシートにつなぐ
フォームの「回答」タブ →「スプレッドシートにリンク」→ 新規作成。

### 3. スプレッドシートを CSV で公開する
スプレッドシートで「ファイル」→「共有」→「ウェブに公開」→ シート「フォームの回答 1」・形式「カンマ区切り形式（.csv）」→ 公開 → 出てきた URL をコピー。

### 4. `config.js` に貼る
```js
FORM_URL: "https://forms.gle/xxxxxxxx",          // フォームの「送信」→ リンク
SHEET_CSV_URL: "https://docs.google.com/spreadsheets/d/e/xxxx/pub?gid=0&single=true&output=csv",
```

※ 公開CSVは Google 側のキャッシュで反映まで数分かかることがあります。
※ 不適切な投稿はスプレッドシートの行を削除すればサイトからも消えます。

## 公開
Settings → Pages → Source: `Deploy from a branch` / Branch: `main` / `/ (root)` → Save。
数分後に `https://konakavn.github.io/wedding-guide/` で見られます。

検索エンジンには出ないよう `noindex` を設定済み。式が終わったらリポジトリを Private にするか削除すれば非公開になります。
